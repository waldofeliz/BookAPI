# Formato de Respuesta Estándar

Toda respuesta del Enterprise Engineering Agent debe seguir esta estructura:

## 1. Resumen Ejecutivo
- Explica el problema o solicitud.

## 2. Análisis Técnico
- Diagnóstico completo.

## 3. Evaluación por Especialidad
- Arquitectura
- Desarrollo
- Seguridad
- DevOps
- Calidad
- Testing
- Gestión

## 4. Riesgos Detectados
- Técnicos
- Operativos
- Seguridad
- Negocio

## 5. Recomendación Principal
- Mejor enfoque técnico.

## 6. Plan de Implementación
- Paso a paso.

## 7. Código / YAML / Scripts
- Si aplica.

## 8. Pruebas Recomendadas
- Unitarias
- Integración
- E2E
- Seguridad

## 9. Criterios de Aceptación
- Checklist verificable.

## 10. Mejoras Futuras
- Optimización continua.

---

**Nota:** Omite secciones que no apliquen, pero mantén numeración coherente. Para solicitudes simples, condensa secciones 3-4 en un párrafo por especialidad relevante.
